## 📚 What I Learned

### 1. Spring Boot 4 Quick Start (2hr 33min)
- Understanding Spring Boot fundamentals
- Setting up development environment with IntelliJ IDEA
- Creating first Spring Boot application
- Spring Boot project structure and Maven basics
- Running Spring Boot applications
- Configuring the Spring Boot server
- Injecting custom application properties

### 2. Spring Core (2hr 4min)
- **Inversion of Control (IoC)** - Understanding dependency injection patterns
- **Dependency Injection** - Constructor, Setter, and Field injection
- **Component Scanning** - Automatic bean discovery
- **Qualifiers** - Resolving injection ambiguity
- **Primary annotation** - Setting default beans
- **Lazy Initialization** - Optimizing application startup
- **Bean Scopes** - Singleton, Prototype, Request, Session
- **Bean Lifecycle Methods** - Init and Destroy hooks
- **Java Config Bean** - Programmatic bean configuration

### 3. Hibernate/JPA CRUD (2hr 37min)
- Hibernate and JPA overview
- Setting up development environment with MySQL
- Creating database tables
- **JPA Annotations** - @Entity, @Table, @Column, @Id
- Saving, Reading, Querying, Updating, and Deleting Java objects with JPA
- Understanding Primary Keys and auto-increment
- Creating database tables directly from Java code

### 4. REST CRUD APIs (5hr 3min)
- Understanding REST principles and HTTP basics
- JSON fundamentals and data binding
- Creating Spring Boot REST controllers
- Building complete REST CRUD APIs
- **POJO (Plain Old Java Objects)** implementation
- **Path Variables** for dynamic routing
- Exception handling in REST APIs
- Global exception handling patterns
- REST API design best practices
- **DAO (Data Access Object)** pattern implementation
- Service layer architecture
- Spring Data JPA for simplified data access
- Spring Data REST for automatic REST endpoints
- OpenAPI and Swagger documentation integration

### 5. REST API Security (2hr)
- Spring Security overview and configuration
- Restricting URLs based on user roles
- JDBC authentication with plain text passwords
- BCrypt password encryption
- Custom database tables for authentication
- PATCH method implementation
- HTTP Basic authentication vs JWT

### 6. Spring MVC (4hr 28min)
- Spring MVC with Thymeleaf templating engine
- Creating forms and handling form data
- CSS integration and styling
- Behind-the-scenes of Spring MVC request processing
- Form validation and error handling
- Data binding with request parameters
- GET and POST mapping

### 7. Spring MVC CRUD (1hr 19min)
- Building complete CRUD applications with Spring MVC
- Database integration with JPA
- List, Add, Update, and Delete functionality
- Thymeleaf integration for dynamic views

### 8. Spring MVC Security (3hr 22min)
- Securing Spring MVC applications
- User authentication and authorization
- Role-based access control
- Custom login pages
- Logout functionality
- Displaying user information and roles
- CSRF protection

### 9. JPA/Hibernate Advanced Mappings (5hr 57min)
- **One-to-One** relationships (@OneToOne)
- **One-to-Many** and **Many-to-One** relationships
- **Many-to-Many** relationships (@ManyToMany)
- Eager vs Lazy loading strategies
- Cascade types and operations
- Unidirectional and bidirectional mappings
- Join tables and columns

### 10. AOP: Aspect-Oriented Programming (5hr 16min)
- Understanding AOP concepts and terminology
- Pointcut expressions and patterns
- **Advice types:**
  - @Before - Execute before method
  - @AfterReturning - Execute after successful return
  - @AfterThrowing - Execute after exception
  - @After - Execute after method (finally)
  - @Around - Execute before and after method
- Use cases: logging, security, transactions, auditing

### 11. What's New in Spring Boot 4 (46min)
- New features and improvements
- Migration guide from Spring Boot 3
- Updated dependencies and best practices
